# v17 前半段特殊词义覆盖与场面设计

本报告只做研究、审查与原创设计，范围 0–74 秒；未更改生产渲染器，未运行 GPU 或 Git。依据 v15 概念库、v16 的 `semantic_score.py`、`semantic_director.py`、`integrated_semantics.py`、`cohesive_geometry.py` 及原场景装配逻辑。从最终 v16 MP4 直接解码 **26 张 1080p 帧**，见 本地联系图 `first_half_v16_contacts.jpg` 与 本地抽样记录 `first_half_v16_samples.json`。机器可读的完整 22 项设计见 [first_half_coverage.json](first_half_coverage.json)。

## 优先结论

最大缺口是 **bag / shrooms、Basilisk、NVDA / moon**：实际 28.4、29.3、61.5、62.5、63.7 秒样本主要是词与通用飞行通道，缺乏可辨认的物体。其次是 servant / boss、优化、原子重组和 Sydney 的动作因果不够明确。中文房间、Shoggoth 面具、单眼、P(doom) 爆炸、现有算力机舱已有自己的形态，应通过它们的真实部件补义。

此轮应让“物件能认出、动作有前后状态、挂在同一世界里”成为目标。前半补义不要求每个名词都新增一个独立主题场景，更不能为凑覆盖再次堆小盒、圆表、箭头、正面芯片与重复扫线。后半 74 秒以后已建立的高质量结构尽量保持。

## 一手来源与解释边界

- **shrooms**：作者只将其解释为困惑；袋口、蘑菇和一次空间错位是本片原创表达。**Sydney**：作者明确指 Bing Sydney；微软一手回顾确认长对话可能产生重复或偏离预设语气。闭环囚笼不是微软所述的具体实现。[歌词作者说明](https://docs.osmarks.net/rev/b3140e5/p%28doom%29_song_objectively_correct_interpretation)、[Bing 首周回顾](https://blogs.bing.com/search/2023/2/The-new-Bing-Edge-Learning-from-our-first-week/)
- **NVDA / moon**：作者确认 NVDA 指股票代码，NVIDIA 官方 FAQ 确认该代码。这里将 moon 作夸张上冲双关，既不是现实股价、收益或预测，也不是 NVIDIA 真正登月。[作者说明](https://docs.osmarks.net/rev/b3140e5/p%28doom%29_song_objectively_correct_interpretation)、[NVIDIA 官方 FAQ](https://investor.nvidia.com/investor-resources/faqs/default.aspx)
- **Basilisk**：作者指向理性主义胁迫梗；Roko 原帖存档可确认其思想实验语境。机械蛇、回望和回折索是原创具象化，不表现“知道此梗就真会受罚”。[作者说明](https://docs.osmarks.net/rev/b3140e5/p%28doom%29_song_objectively_correct_interpretation)、[原帖存档](https://basilisk.neocities.org/)
- **Omega Point**：作者链接的是 Orion's Arm 的 Omega 神学条目；这是虚构世界中的哲学/末世汇聚意象，不能当成已验证宇宙学。[作者说明](https://docs.osmarks.net/rev/b3140e5/p%28doom%29_song_objectively_correct_interpretation)、[作者所链原条目](https://www.orionsarm.com/eg-article/483b1d57a9f34)
- **1e30 / safe enough**：作者明确未指某项特定法规，表达对巨大算力投入的讽喻。因此不加入虚构法规阈值或审批机构名称。[作者说明](https://docs.osmarks.net/rev/b3140e5/p%28doom%29_song_objectively_correct_interpretation)
- **Chinese room**、**FOOM**、**singularity**分别沿用符号理解思想实验、快速智能爆炸假说、技术奇点界点；它们不是一组已发生的事实。[Searle 原文](https://cse.buffalo.edu/~rapaport/Papers/Papers.by.Others/Searle/searle80.html)、[Intelligence Explosion: Evidence and Import](https://intelligence.org/files/IEM.pdf)、[Vinge 原文](https://cseweb.ucsd.edu/~goguen/misc/singularity.html)

开篇由 MusicPerson 创作，osmarks 对其若干解释也明说是推测；尤其 Shinigami 在歌词中的具体关系未被作者确定。原单眼已经得到用户认可，不再强行添加寿命数字、钟表或另一只眼。Sparks 可联想同名 [GPT-4 论文](https://arxiv.org/abs/2303.12712)，也不把该联想画成 AGI 认证结论。

## 三处优先构图

### 蘑菇袋：延长中文房间的出口动作

27.28 秒已启动 ROOM 飞行，28.4–29.3 秒镜头会把原房间工位留在身后。因此袋子必须装在 **实际航线前方的出口投递台**。桌面接回原轨道，袋口由实体挂钩和绳固定；袋口至少有三朵不同方向的伞盖、柄与菌褶。28.34 秒 bag 时先读出袋形，29.12 秒 shrooms 时从一朵菌盖下斜掠，看清放射菌褶，别只给几个球与杆。

只做一次动作：投递机构拉开袋口，菌盖遮过镜头时规则槽有限错位，然后在后景接回。蘑菇不在空中无限旋转，不在屏中凭空长成一张图标；原来的符片输入—规则匹配—输出仍在后景走完。物件可以在词前出现，歌词字形仍严格跟唱。

### NVDA → moon → Omega：同一设施连续变化

62.34 秒从 GPU 一体机舱的斜侧面起，散热折片和互联先成为具体尺度参照。载台锁在原机架伸出的弯曲升轨上，一次抬升带出远处的大月弧。月面应有大小不同的撞击坑，不用一颗小浮球代替。63.35 秒已能看到月面，63.76–64.06 秒 moon 短词窗才足够读出含义。

升轨在月面设施接住；64.22 秒 Omega 时，把这一组真实轨道收束到同一核心，而不是突然换成一张向心线网。轨道、设施和焦点始终有连接，月弧后退成为汇聚的外圈。整段不用 K 线展板、上升数字、正方芯片火箭或公司 Logo。

### Basilisk：蛇是轨道的一部分

P(doom) 第二爆之后镜头高速前进，蛇必须在 61 秒航线前方。分节蛇身用接箍固定到原轨道，形态要有楔形头、颈部和腹节，不能仅凭两只亮眼代表。一次回望拉紧一根有真实两端的回折索，轨道分叉随之收紧；boom 时可用甩头与压缩增强张力，但爆炸继续留在 P(doom) 词点。相机从尚未合拢的蛇圈中飞过，动作只发生一次。
