# v17 第一轮 64 帧预览复核

**结论：P0 尚未通过，需要修正袋子的安装感、Basilisk 可见性和登月段的亮度层级后再编码。**

已实际查看 `meaning_page_1.jpg`–`meaning_page_4.jpg` 的全部 64 格，以及 `bag-2/3.jpg`、`serpent-1/2.jpg`、`moon-2/3.jpg` 六张原生 1080p 图。仅查看图片和代码，无 GPU 执行或生产修改。

## 必须修正

### 1. 蘑菇可辨，但袋与托盘不可辨

29.15 / 29.4 秒的伞盖、柄和菌褶可以识别，方向正确。但它们呈现为三组发白蘑菇悬在黑通道中；袋只剩后方暗淡的几道薄圈，托盘没有清楚外轮廓。没有看到“袋里装着蘑菇、袋放在出口工位”的关系。这仍接近用户不喜欢的独立装饰层。

建议优先调整已有物体：袋壁高度由约 2 单位提高到约 4–5 单位，保留不对称敞口、少量明显垂褶和真正支承它的托盘。让袋口/袋侧剪影及托盘外缘达到约当前的 1.5–2 倍可见亮度，同时蘑菇伞盖降低约 20% 增益，避免密线发白。无需增加更多蘑菇或更多细线。

验收：28.4 BAG 能先看出敞口袋，29.15 / 29.4 能顺着菌柄找到袋底与承重托盘。袋和台不能仅靠“代码里存在”判通过。

### 2. Basilisk 在四个样本中均未形成蛇的轮廓

60.45、61.15、61.65、62.1 的联系图及两张原图，主体仍是旧通道白线和 BASILISK / BOOM 字形。无法指出楔形头、颈、连续腹节或一圈可追踪蛇身。此处词义覆盖仍未完成。

需要把主头放在实际航线前方可见处，主头占约 15–25% 画宽；至少一到两圈连贯身体与头连接，避免头和体各自漂浮。局部将旧通道减到当前约 30–40% 的增益或采取等效主体对比，不要仅全局加亮蛇来与背景对抗。仍保留现有爆点与字面穿越时间。

验收：61.15 先认出蛇，61.65 字面掠过时仍能沿一段身体找到头，62.1 看到一次咬合/压缩后果。不能只有几只亮眼代替动物。

### 3. 月球已有坑纹，月面/设备/旧通道亮度混成一层

63.85 秒原图能辨认坑纹，升轨也确实连向球体，几何本身不需重造。但月表、升轨、算力站和旧通道同时接近亮白，NVDA 对应机舱变成白网；缩图会把月球读成一颗发光毛线球。

保留坑纹与外轮廓，降低月表底网和旧通道，算力设备留一套近景斜侧面作为尺度参照。三层关系应是“有散热片的计算设施 → 上升轨 → 有坑纹的月面”；不要增加 K 线、文字标签或公司 Logo。63.1 的巨型字面属于既定穿越，可保留；物体须在它前后有足够可读时间。

验收：63.85 的坑纹和 64.0 的球体外轮廓在 480px 缩图仍成立，能沿升轨反向找到一台有体积的计算设施。

## 可保留

- 开场与 Shinigami 仍是已恢复的单眼球，没有回归双瞳或时钟。
- circuits 的接点与原线束连接良好；没有重新出现四枚正面芯片或循环前景红扫线。
- ChatGPT 的吞噬门、P(doom) 爆点、损失飞行、中文房间与 Shoggoth 仍保持原有空间语法。
- 前半多处新增部件偏克制，控制、训练、优化、原子与检查工位可在修正 P0 后按近景动作再抽样；目前不建议机械提高所有部件增益来追求满屏。
- 75.0 / 92.5 / 111.7 / 119.7 及尾声四格保持 v16 风格，后半不需扩大改动。

本结论为预览复核，不是最终编码验收。
