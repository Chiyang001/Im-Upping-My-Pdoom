# P(doom) — Cinematic Edit

成片：output_v6/Pdoom_Cinematic_Edit_1080p.mp4。

本版保留纯代码线条、三维歌词和红色信号的连续叙事，重做段落之间的剪辑。全片由17个持续移动镜头组成，在16个音乐攻击点真正切换机位和空间截面；转场动作只占3–7帧，随后保持新机位继续运动。

## 源码与复现

从项目根目录执行：

```powershell
python v6/render.py
python v6/render.py --edits
python v6/render.py --sample 18
python v6/render.py --audit
python v6/validate_v6.py
```

- render.py：绘制、镜头合成、程序化快门、短时运动模糊与成片输出。
- edit_director.py：16个切点、17个镜头的持续机位及局部移镜、环境归属与短时动作。
- validate_v6.py：全片解码、音轨位流比对、切点前后逐帧片条。
- edit_events.json、beat_alignment.json：剪辑点和攻击点对齐记录。
- compositions.json：每个完整镜头固定的取景余量与红信号匹配校准。

沿用v5的camera_path.py、world_layers.py、story_geometry.py和v4／code3d中的线条几何。画面不使用图片、背景视频或文字纹理；所有字形都是三维轮廓线几何。仅复制参考片的原始音轨。

规格：1920×1080、30fps、156.667秒、H.264、4×MSAA，原始AAC音轨直接复制。Python依赖与v5相同。
