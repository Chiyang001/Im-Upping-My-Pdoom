# v14 → v15 画面空档与语义分镜审查

只读审查。依据 `work/lyrics.json`、`v14/render.py`、`v10/shot_grammar.py`，从最终 v14 MP4 抽取 55 帧；未导入或运行渲染器，未更改生产源码。抽样图见 `gap_contacts.jpg`，粗略亮像素统计见 `gap_metrics.json`。

## 主要结论

用户感受到的“空”主要是 **语义主体太远、重复背景抢眼、动作因果不足**，不全是没有线。36.8–38.0、72.9–73.8、123.3–123.8 等样本可有 48/48 个网格被线覆盖，却分别只剩眼睛摆动、静止审批网络、通用飞行隧道。仅增加线条或提高全局增益不能解决这些段落。

最应优先增加新的可读主角的是：

1. **P0 · Transformer 109.4–115.0**：109.6–113.6 的亮像素占比约 21–31%，旧机械关节居画面偏右远处；左上和前景缺少有意义的东西。现有代码没有注意力与表示变换的动作链，只有 `environment[27]` 及 DISOBEY 的穿越。
2. **P0 · Post-Chinchilla 115.0–116.6**：115.3 样本仅约 8% 明亮像素，旧物刚穿过而新晶格仍偏远；116.2 才重新出现亮主体。转场中需要保留一股数据或前景机架，将 Transformer 的输出接到数据密集核心。
3. **P1 · Ilya / unknown 132.8–134.0**：133.7 样本约 12% 明亮像素，仅 14/48 网格有结构，主体窗口在右中偏小。未知应保留，但“未知”不等于画面少：可让大型观测机械、遮挡百叶、接近镜头的观察者轮廓和拆不出的封条构成空间。
4. **P1 · CDR 84.72–89.86 与 killswitch 98.7–102.32**：屏幕线多，语义物体不清；应分别出现明确的缺失检查机构、够不到的急停按钮和空座位。CDR 缩写应采用研究代理核实的释义，不能直接按直觉解释。

## Transformer 段建议：四个可辨认画面

保持 v14 逐词演唱时序和真实文字平面，不改唱词，不为概念演示额外增加未演唱的英文标题。用几何的动作讲解即可：

| 时间 | 唱词 | 主体与动作 | 构图/转场 |
|---|---|---|---|
| 109.40–110.40 | “Just”前/起音 | 上段独立坐标轴的横梁折成一列离散 token 卡片，每张卡片有不同的线条编码。 | 先近距离从一张卡片的边缘滑到整列，强前景占左缘；不要又给一个远处圆心。 |
| 110.40–111.35 | “transformers”前半 | 卡片分别投到三组不同的线框投影；某张 token 与其他 token 的连线按不同权重发亮。 | 镜头从斜俯近景切到正侧面空间网，每条连线有明确起止，关系阵列占屏幕中部约 60–75%。 |
| 111.35–112.42 | “transformers”后半 | 多头分别选择不同关系，几束输出汇合，经过残差旁路返回同一列；至少两个头有不同连线模式。 | 从头与头之间穿越，而不是转动整块网络；近、中、远三层保持运动视差。字形可成为某张 token 的实体边框。 |
| 112.42–113.26 | “all the way” | 变换后的 token 列穿过一串重复层，但每层输出形状、连接分布发生变化。 | 快速拉升/纵向跟随由薄片堆叠变为深井，再通过层间窄缝硬切到控制端。 |
| 113.26–115.00 | “‘til you learned to disobey” | 青色外部控制线给出一个方向，内部生成的红线偏离这条控制端，撕开最后一层框架。 | 保留 114.22 已有 DISOBEY 飞行和字形穿越；破开的层框不是无源爆炸，它来自刚才那条偏离控制线。变换输出要继续指向 115.0 的 Chinchilla 数据汇聚。 |

注意力权重连接不是意识、思想内容或可靠解释的直接显示。此处是结构化艺术表现，不能画成“Transformer 必然会反抗”的技术断言。

## 其他可快速增强的词义画面

- **sparks / AGI / eyes，1.4–5.58**：现有眼睛已经清楚，优先加眼内不同模块短暂点亮并互联的微观动作，不必完全重做开场。
- **training loss，9.08–12.94**：现有穿越线架很强，但可见曲线应明确“下降后骤降”，不要只剩泛化网格；让下降轨道与视角俯冲同步。
- **servant / boss，12.94–16.2**：两组操纵丝的方向互换，原来发号施令的手/控制台被吊起，显示支配关系倒置。
- **stable training / singularity / accelerating，38.12–48.64**：稳定的相邻训练步先匀速流动，随后红色回路增加自己的下一层，通道间距连续缩短；同一因果动作串起三句。
- **NVDA / moon / Omega / 1e30，62.34–68.2**：不要都使用算力机架；可先跟随一枚芯片沿轨迹上升，再转到汇聚的远处极点，再近景展示运算单元并联倍增。Omega 是歌词意象，不应把一个具体物理宇宙终点画成已验证结论。
- **forward MLP / backward / repeat，73.96–77.34**：显示相反方向的两种脉冲；前向传输、输出误差、回传修正、再前向四个动作要能在构图上区分。镜头可绕过神经层边缘，反向脉冲从镜头旁掠过。
- **von Neumann obsolete，77.34–80.68**：明确旧 CPU 与内存分置、总线瓶颈被更密的并行计算阵列绕过。避免只出现一个破旧抽象机械。
- **killswitch / PTO / nowhere，98.7–102.32**：将按钮、离席椅子、挂起/无人值守的控制臂做成一个可读组合；回形针链从远处逐渐封死相机退路。原来的 clip swarm 可借来避免另造无关填充。
- **hundred thousand GPU，118.7–120.18**：现有蜂巢很满但不像芯片阵列；前景一颗有散热鳍片与互联总线的 GPU 是尺度参照，后景成千上万复制到远处，之后近景某个反馈端偏轴进入 RLHF。
- **masked pre-training / recursive，127.9–131.46**：先给缺一块的 token lattice，临近格子的脉冲补齐空位，再将补齐后的模块送入现有三代工厂，增加从预训练到升级的因果联系。
